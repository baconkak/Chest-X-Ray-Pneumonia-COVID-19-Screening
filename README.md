# Chest-X-Ray-Pneumonia-COVID-19-Screening
ระบบคัดกรองและตรวจจับโรคปอดบวม (Pneumonia) และ โควิด-19 (COVID-19) จากภาพถ่ายเอกซเรย์ทรวงอกโดย automated Deep Learning Model ช่วยประมวลผลและสนับสนุนการวินิจฉัยทางแพทย์เบื้องต้นด้วยความแม่นยำสูง ลดระยะเวลาและภาระงานของบุคลากรทางการแพทย์ในการจำแนกประเภทภาพถ่ายทางรังสีวิทยา
