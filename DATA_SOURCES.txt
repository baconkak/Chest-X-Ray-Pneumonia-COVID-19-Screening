Dataset and attribution record (checked 18 October 2026)
======================================================

Latest setting, 23 October 2026: the original quick profile is restored as default,
using nih-chest-xrays/data/versions/3 (full download, then up to 3,000 patients).
Use full profile to train all patients. Both require at least 110 GiB free disk.
The smaller NIH sample remains an optional profile as documented below.

Earlier update 23 October 2026: added the publisher's NIH Random Sample,
https://www.kaggle.com/datasets/nih-chest-xrays/sample (version 4).
Kaggle metadata lists 5,606 images and 2,252,611,005 bytes; sample_labels.csv
was checked directly and contains 5,606 rows with 62 Pneumonia-positive images.
This is a 5% sample of the same NIH dataset, not a different disease dataset.
All available sample images are retained, with a grouped patient split.
Rare positive support limits evaluation precision. Do not compare sample scores
directly with official full-data benchmarks. Full data mode uses version 3.

Chosen dataset: NIH ChestX-ray14, provided by NIH Clinical Center.
NIH original download: https://nihcc.app.box.com/v/ChestXray-NIHCC
Kaggle distribution: https://www.kaggle.com/datasets/nih-chest-xrays/data
Dataset files are downloaded by the user at runtime and are not redistributed in Git.
The notebook records the resolved Kaggle cache version path, metadata SHA-256,
exact split manifests and code commit. Preserve those records with each experiment.

Citation:
Xiaosong Wang, Yifan Peng, Le Lu, Zhiyong Lu, Mohammadhadi Bagheri,
Ronald M. Summers. ChestX-ray8: Hospital-scale Chest X-ray Database and
Benchmarks on Weakly-Supervised Classification and Localization of Common
Thorax Diseases. CVPR 2017. ChestX-ray14 update is described in the appendix.
https://arxiv.org/abs/1705.02315
https://doi.org/10.1109/CVPR.2017.369

Attribution guidance:
https://docs.cloud.google.com/healthcare-api/docs/resources/public-datasets/nih-chest
Consult the original dataset and the Kaggle distribution's current terms before use.
This project acknowledges NIH Clinical Center and links the original download and paper.
Google Cloud's NIH bucket is Requester Pays, so this notebook does not use it as a free download workaround.

Label contract: 14 thoracic findings, with possible co-occurring findings, plus No Finding.
COVID-19 is absent from the original label vocabulary. Do not manufacture COVID labels.
Labels are extracted from radiology reports and are imperfect reference labels.
Pneumonia-absent does not mean normal, healthy, or COVID-negative.
